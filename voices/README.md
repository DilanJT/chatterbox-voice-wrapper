# voices/

Put voice samples here (they are git-ignored, so they never get committed).

- Clean speech, 10–30 s, one speaker, no music, no echo. WAV or MP3.
- `my_voice.wav` (or `.mp3`) is the default. Any other file can be picked by name, e.g. `voice="sara.mp3"`.
- The turbo engine needs a sample longer than 5 s.
- Only clone voices you have permission to use.
